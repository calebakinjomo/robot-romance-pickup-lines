One pickup line, aimed at an AI — the autocomplete premise turned into the classic rom-com line:

> I must be your prompt, because you keep completing me.

54 characters, one line, no batteries, charging, or rebooting in sight. The joke only works because the target is a language model that completes prompts.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
